# 🕷️ Spider-Track | Map Client

> **Spider-Track** es una aplicación móvil inspirada en la interfaz táctica y radar de rastreo del universo de Spider-Man. Su objetivo principal en esta fase inicial es proveer una visualización fluida de mapas interactivos en tiempo real sirviendo como base para la posterior integración de más funcionalidades como colecciones de lugares, adición de fotos para los usuarios, etc.

## 🛠️ Stack Tecnológico

| Componente | Tecnología | Propósito |
| :--- | :--- | :--- |
| **Frontend / Mobile** | [Flutter](https://flutter.dev/) (Dart 3.x) | Framework multiplataforma de alto rendimiento |
| **Visualización Mapa** | Flutter Map / Mapbox SDK | Renderizado de teselas y capas tácticas |
| **Backend (Próximamente)** | [FastAPI](https://fastapi.tiangolo.com/) (Python) | API REST asíncrona de alto desempeño |
| **Base de Datos** | [MongoDB](https://www.mongodb.com/) | Persistencia de ubicaciones con soporte de índices `2dsphere` |
| **Inteligencia Artificial** | [Gemini API](https://ai.google.dev/) | Análisis contextual y asistencias tácticas |
| **Control de Versiones** | Git & GitHub | Gestión de ramas, commits convencionales y seguimiento ágil |
